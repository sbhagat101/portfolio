# 🧑‍💻 Developer Portfolio

A personal **developer portfolio** website built with **React.js** and **Tailwind CSS**, designed to showcase projects, skills, and contact information in a clean, responsive layout.

## 🚀 Live Demo

[🌐 View Live Portfolio](https://sbhagat101.github.io/portfolio/)

## 🛠️ Features

- 💻 Modern and responsive design
- 🧩 Built with React and Tailwind CSS
- 🗂️ Sections include:
  - Hero banner
  - About me
  - Skills / Tech stack
  - Projects showcase
  - Updated Resume Download
- 🌐 Fully responsive across devices
